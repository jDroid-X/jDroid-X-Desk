### Ponytail Decision Ladder if code is between 1800 to 2000 lines

Before writing new code, evaluate the following:

1. Does this need to exist ?
2. Can existing code be reused (OOPS base MVC/MVVM Structure components)?
3. Can the standard library handle it?
4. Can the native platform feature handle it?
5. Can an installed dependency handle it?
6. Can it be minimum lines (refrencing OOPS base MVC/MVVM Structure components) ?
7. Then write the minimum that works as part of OOPS and MVC or MVVM structure.

### Execution

- **Implement the leanest solution not exceeding between 1800 to 2000 lines**
- **Deliver working solution OOPS base MVC/MVVM Structure using Waterfall method**
