# /antigravity-flow: Master Enterprise Multi-Agent Execution

When the user invokes `/antigravity-flow`, execute the comprehensive **7-Stage Simple Waterfall (OOPS based MVC) – Closed Loop Workflow From Idea To Final Product** defined in [ANTIGRAVITY_FLOW.md](file:///c:/Users/jiten/jAnitGravity/.kit/ANTIGRAVITY_FLOW.md).

## 7-Stage Execution & Deliverables

0. **Stage 0: PONYTAIL CHECK**
   - Execute: Run the Ponytail Decision Ladder. If resolved via native solution or minimum lines (Steps 1-6), bypass the 7-stage waterfall. If custom architecture is required (Step 7), proceed to Stage 1.

1. **Stage 1: INITIATE & PLAN**
   - Execute: Identify Problem → Market/User Research → Define Goals → Feasibility Analysis → Define Scope → Create Project Plan → Budget & Timeline → Approval & Kickoff.
   - Reconnaissance Hook (REA MCP): For tasks requiring reverse engineering, decompilation, or cloning existing app/binary/APK features, Security Auditor (11) invokes REA MCP to extract ground-truth bytecode and API contracts before finalizing requirements.
   - Deliverables: **Project Plan, Feasibility Report, REA Evidence Package (Optional)**.
2. **Stage 2: REQUIREMENTS ANALYSIS**
   - Execute: Stakeholder Interviews → Requirement Gathering → Analyze & Document → Requirements Validation → Prioritize Requirements → SRS Sign-off.
   - Deliverables: **SRS Document, Use Case Document**.
3. **Stage 3: SYSTEM DESIGN (SCREEN-FIRST OOPS MVC ARCHITECTURE)**
   - Execute: Screen Layout & UI/UX Design (View: Hierarchy & Affordance Matrix) → Controller & Screen Action Logic Design → Database Design (Model derived from Screen State) → Class Diagrams & Interface Contracts → Architecture Sign-off.
   - Deliverables: **UI/UX Design & Affordance Matrix, System Design Doc, Database Schema**.
4. **Stage 4: IMPLEMENTATION (CODING - OUTSIDE-IN SEQUENCE)**
   - Execute: Setup Development Env → Develop Views & Reactive UI Components → Develop Controllers & Screen Action Handlers → Develop Models & DB Tables → Integrate Components → Code Review → Build / Compile.
   - Deliverables: **UI Views & Components, Controllers, Database & Models, Source Code**.
   - Enforce Dynamic OOPS based MVC interaction: `User ➔ View (Actions) ⇄ Controller (Handlers) ⇄ Model (Data)`.
5. **Stage 5: TESTING**
   - Execute: Test Plan Creation → Unit Testing (Model, View, Controller) → Integration Testing → System Testing → UAT → Fix Defects → Test Sign-off.
   - Deliverables: **Test Cases, Test Reports, Bug Reports**.
6. **Stage 6: DEPLOYMENT**
   - Execute: Server Setup → App Build / Package → Configuration Setup → Database Migration → Deploy Application → Smoke Test → Go Live.
   - Deliverables: **Deployed Application, User Manual, Release Notes**.
7. **Stage 7: MAINTENANCE & SUPPORT**
   - Execute: Monitor Application → Log & Error Tracking → Issue / Bug Reporting → Fixes & Patches → Optimize Performance → User Support → Enhancements.
   - Deliverables: **Support Reports, Change Logs, Updates**.

## Closed Loop Feedback Convergence
Whenever feedback, defects, or enhancements are identified:
`User Feedback -> Analyze -> Identify Issues & Improvements -> Update Plan & Requirements -> Implement Changes -> Re-Test & Deploy`
All branches must converge back into this closed loop with single-pass verification.
