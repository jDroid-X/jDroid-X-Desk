2. Toggle theme between 15 universal themes instantly without page reload.
3. Switch open-source streaming engine (Sunshine / RustDesk / Guacamole / jDroid-Relay).
4. Run automated startup scripts for active engines.
5. Export portable client binaries (.exe and .bat).
6. Filter device fleet by group and query keywords.
7. Manage whitelist Safe Zones (CIDR IPs) and Guardians.
8. Customize dynamic settings (ports, timeouts, display quality, audio, proxy, Colab relay).
9. Audit and export real-time request and processing logs.
10. Trigger emergency one-click session disconnection.
