==============================================================================
1. SCREEN PURPOSE & OBJECTIVES
==============================================================================
Provides central administrator supervision, open-source model switching, processing limits management, and live log auditing across:
1. RustDesk (rustdesk/rustdesk) - Direct Match P2P Engine
2. Sunshine & Moonlight (LizardByte/Sunshine) - Lowest Latency In The World
3. Apache Guacamole + FreeRDP (apache/guacamole-server) - Clientless HTML5 Web Gateway
4. jDroid-X Async Binary Relay - Multi-Threaded Colab Cloud Streaming Bridge

==============================================================================
2. USER AFFORDANCE MATRIX
==============================================================================
- [Actively Switch Engine]: 1-click active engine toggle between Sunshine, RustDesk, Guacamole, and jDroid-X Relay.
- [Engine Quick Launchers]: Direct external links to Sunshine Web UI (https://localhost:47990), RustDesk rendezvous, and Guacamole.
- [Hardware Telemetry Gauges]: Real-time live CPU Cores + %, RAM Total / Free / Usage %, Uptime, Active Sessions count.
- [Processing Limits Controls]:
  * Max Concurrent Sessions (1-50)
  * Bandwidth Ceilings (Mbps)
  * Maximum Target FPS (30 / 60 / 120 FPS)
  * Idle Disconnect Timeout (Minutes)
  * 7-Day Log Retention & Auto Purging
  * Hardware Acceleration Mode Selector (NVENC + CUDA / Direct3D / Software)
- [Live Log Audit Stream]:
  * Live-updating table with Packet ID, UTC Timestamp, Level, Stage/Method, RTT (ms), Client IP, and Message.
  * Filters: ALL, INFO, WARN, ERROR, AUDIT, HTTP_TRAFFIC, ENGINE_SWITCH.
  * Real-time text search by IP, route, or keyword.
  * 1-Click JSON export and purge actions.

==============================================================================
3. API CONTRACTS
==============================================================================
- GET    /admin or /admin.html    -> Serves responsive standalone Admin Page
- GET    /api/admin/config        -> Returns serverConfig & processing limits
- PUT    /api/admin/config        -> Updates limits, engines, or active engine
- POST   /api/admin/engine/switch -> Switches active engine & records audit log
- GET    /api/admin/metrics       -> Real-time hardware telemetry and session metrics
- GET    /api/admin/logs          -> Filtered server processing and request logs
- DELETE /api/admin/logs          -> Purges old logs
