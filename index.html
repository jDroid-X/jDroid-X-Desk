User Manual (Step-by-Step)

Primary to Secondary Remote Control Workflow

  1. Step 1 (Host Run): Secondary user runs app. Device Address `984-102-391` is assigned.
  2. Step 2 (Exchange ID): Secondary user shares address with Primary technician.
  3. Step 3 (Connect): Primary user enters address, inputs password, and clicks Connect.
  4. Step 4 (Remote Control Active): Remote screen window opens. Primary user moves mouse and types text on secondary machine.
