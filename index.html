Help & Multi-OS Operations Guide

System Prerequisites & Network Ports:

Node.js Prerequisite: Node.js v16.0.0 or higher must be installed.
Express Server Port: TCP Port 12345 (Local Web Interface & API).
STUN/TURN Signal Port: UDP Port 21116 (Encrypted P2P Handshake).

Cross-Platform Installation Procedures:

  • Windows 10 / 11: Run install_windows_app.bat. Starts Node server, launches Edge App Mode, and adds PowerShell System Tray icon.
  • macOS / Linux: Open terminal in directory, run npm install, then node server.js. Access via http://localhost:12345.
  • Mobile (Android / iOS): Open Chrome or Safari and enter http://<HOST-IP>:12345. Features responsive mobile layout.

User Manual & Root Cause Analysis (RCA) Guide

Human-In-The-Loop (HITL) Operational Manual & RCA Protocol

Step-by-Step Multi-OS Setup & 10-Field Log Audit Diagnostics

Part 1: Human-in-Loop Execution Workflow

  1. Step 1 (Multi-OS Launch): Run install_windows_app.bat (Windows) or node server.js (macOS/Linux/Mobile). Server initializes on port 12345.
  2. Step 2 (Host Identification): Host node displays 9-digit System Address 984-102-391 and one-time passcode.
  3. Step 3 (Human Number Exchange): Secondary user shares System Address with Primary Technician via secure channel.
  4. Step 4 (Encrypted Handshake): Primary technician enters address and password into Step 2 card and clicks Connect.
  5. Step 5 (Remote Screen Interaction): Primary user interacts with secondary screen. Stream quality auto-adapts (1080p / 720p / Turbo).
  6. Step 6 (Tray Exit & Disconnect): Click Disconnect or right-click System Tray icon to safely terminate connection.

Part 2: 10-Field Log Metadata & Human Root Cause Analysis (RCA) Guide

Every telemetry entry contains 10 auditable metadata fields updated continuously (every 2.0s) and on instant events (0ms):

1. Packet ID (e.g. TRC-1001) - Sequence ordering verification
2. Timestamp (UTC ISO format) - Exact event timing
3. Level (INFO / TRACE / WARN / ERROR / SECURITY_AUDIT) - Severity rating
4. Stage (STUN_HANDSHAKE / KEY_EXCHANGE / INPUT_INJECT) - Protocol step
5. Source Node - Originating IP & System ID
6. Target Node - Destination IP & System ID
7. RTT Latency (ms) - Network round-trip response time
8. Ed25519 Cryptographic Signature - Packet anti-tampering hash
9. Payload Message - Human-readable event description
10. Compliance Status - Regulatory audit tag (VERIFIED_AUDITABLE)

How Humans Perform Manual Root Cause Analysis (RCA):

  • RCA Scenario 1: Connection Failures → Look for Stage STUN_HANDSHAKE with Level ERROR. Cause: Firewall blocking UDP Port 21116 or Target Offline.
  • RCA Scenario 2: High Mouse/Keyboard Lag → Look for Stage INPUT_INJECT where RTT > 120ms. Cause: 4G network congestion. Fix: Select Turbo Mode (480p).
  • RCA Scenario 3: Unauthorized Connection Attempt → Look for Level SECURITY_AUDIT with invalid hash. Cause: Wrong passcode or un-whitelisted IP. Fix: Add IP to Safe Zones.

jDroid-X-Desk is an ultra-lightweight, unified remote desktop console. Built by Antigravity AI, it features seamless connectivity and continuous system traceability.

How to use

  • Share your ID: Give your 9-digit System Address and One-Time Passcode to a trusted technician to allow them to control this device.
  • Connect to a device: Enter a partner's System Address and Passcode to remotely view and control their screen.
  • System Tray: The app runs silently in the background. Use the System Tray icon near your clock to re-open or fully exit the app.
